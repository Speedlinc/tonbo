## Android (샤오미 / 화웨이 / 홍미 포함)

- APK를 다운로드해 원클릭 설치, 샤오미·화웨이 등 기종 호환성 최적화 완료
- 일부 기종은 Google 서비스 프레임워크 설치 후에야 Google / Gemini 계정 로그인 가능
- 클라이언트 열기 → 로그인 → 원탭 연결, AI 스마트 라우팅이 자동으로 최적 노드 선택
- 헤비 사용은 클라이언트 내에서 전용 노드 / 전용 IP로 전환 가능

## iOS / iPadOS

두 가지 방식 중 하나를 선택하세요.

- **공식 클라이언트**: App Store 또는 공식 사이트 안내로 설치, 로그인 후 원탭 연결
- **Shadowrocket / Quantumult X**: 공식 제공 설정을 가져오기, 세밀한 제어를 선호하는 사용자에게 적합

팁: iOS 첫 연결 시 「VPN 구성 추가」 시스템 권한 요청이 뜨면 허용을 누르면 됩니다.

## Windows

- 공식 사이트에서 설치 파일 다운로드, 더블클릭으로 설치
- 계정 로그인 → 원탭 연결, 시스템 레벨 프록시 자동 인계
- Kill Switch와 DNS 누출 방지 내장, 끊겼을 때 무방비로 노출되지 않음
- 코딩 / Claude Code 실행 시 AI 스마트 라우팅을 켜두면 장시간 연결이 더 안정적

---

## macOS (Apple Silicon + Intel)

- Apple Silicon(M 시리즈)과 Intel 네이티브 지원
- 설치 후 로그인 → 원탭 연결
- macOS 네트워크 스택에 맞춰 최적화해 지연이 더 낮고 전력을 더 아낌
- IEPL 전용선과 함께 쓰면 Claude Code, 긴 작업이 끊김 없이 직접 연결

## Linux (개발자)

- 명령줄 클라이언트 제공, 서버 / 개발 환경에 적합
- git clone, docker pull, npm install 등 툴체인 가속에 적합
- 긴 작업은 IEPL 전용선 + 전용 IP를 타면 안정적으로 중단 없이 진행
